# Make-video: конвейер

Работай по этапам. После этапов **2** и **3** остановись и покажи результат пользователю — дальше правки дорогие.

## 0. Вводные
Выясни: тема, длина (по умолчанию 60–120 с, ≈ 150–330 слов), целевая аудитория, тон. Придумай `slug` (латиница-через-дефис). Создай `videos/<slug>/`.

## 1. Исследование — агент `researcher`
Результат: `videos/<slug>/sources.md` — факты, у каждого URL, дата, пометка «может устареть». Ты читаешь только сводку и список чисел.

## 2. Сценарий — агент `scriptwriter` → **показать пользователю**
Текст озвучки по сценам, ≤ 16 слов в предложении, хук в первой фразе, концовка с призывом (например, поправить в комментариях). Каждое число — из `sources.md`. Утверждение — «можно / нельзя / обещают» — формулируй так, чтобы оно совпадало с источником.

## 3. Раскадровка — агент `director` → **показать пользователю**
Результат: `videos/<slug>/script.json` (схема: `src/types.ts`). Для каждой сцены: `look` (`cartoon` | `info`), элементы `items` с `cue`-словом, тон (`good`/`bad`/`info`). Чередуй: мультяшная сцена → инфографика → …; блок рисков — `mood: "danger"`.

## 4. Озвучка
`python3 scripts/tts.py <slug>`. Если нет сети до TTS-хоста — `--fake` для проверки вёрстки и скажи пользователю, что звук нужно сгенерировать там, где доступ есть.
Проверь: длительность в рамках, нет «не нашёл слово-триггер».

## 5. Сборка и рендер — агент `motion-designer`
Нужен новый элемент/сцена — добавляй в `src/components/` по существующим образцам, без копирования чужого кода.
`node scripts/render.mjs <slug> --still=<сек>` на каждую сцену, потом полный рендер.

## 6. Контроль — агент `qa`
Кадры по сценам + сверка чисел со `sources.md` + список замечаний. Исправь, пока не останется критичных.

## 7. Сдача
Положи `out/<slug>.mp4`, коротко опиши: длительность, голос, источники, что пользователь должен проверить сам. Коммит — только по просьбе.
