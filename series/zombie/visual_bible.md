# Визуальная библия сериала «Зомби: инструкция по выживанию» (рабочее название)

Формат 1080×1920, 30 fps. Ассеты генерирует нейросеть слоями, анимация собирается в Remotion.
Референс: контактный лист `scratchpad/ref/sheet1.jpg` (плоская 2D тёмная комедия). Мы берём **приёмы** (свет, композиция, ритм), не копируем персонажей, сюжет, реплики и кадры. Всё оригинальное, герои и монстры другие.

## 1. Разбор референса: что делает стиль узнаваемым

### 1.1 Палитра (hex, оценка по листу)
| Роль | Hex | Где |
|---|---|---|
| Тёплая стена (жёлто-оливковая) | `#8E7F4B` / тень `#5E5430` | интерьеры «дня» |
| Грязно-зелёная панель/плитка | `#2F4A32`, `#3B5A3C` | низ стен, подъезд |
| Ночной синий | `#1A2740` / `#0F1A2E` | ночные комнаты |
| Красная «ад»-заливка | `#7A0F12` фон, `#B01E1E` света, `#2A0505` тени | кульминация |
| Силуэт монстра | `#0A0A0D` | почти чёрный, без деталей |
| Свет глаз монстра | `#FFF4C8` (ядро), гало `#FFE9A0` | единственный акцент в тьме |
| Кожа героя | `#B98660`, тень `#8A5F40` | |
| Одежда героя | майка `#D8D3C2`, штаны `#1F2B55` | холодное пятно на тёплом фоне |
| Яркий акцент одежды | оранжевый `#E8661A` | единичный «взрыв» цвета |
| Лампа/свет из окна | `#FFD98A` тёплый, `#BFD4E8` холодный | |

Правило: фон 70% приглушённый грязный, герой — чуть светлее и контрастнее фона, **один яркий акцент** на кадр (глаза, оранжевый, красный).

### 1.2 Свет
- Плоская заливка + **мягкая виньетка** по краям (затемнение 25–45%) и лёгкое «грязное» зерно/подтёки на стенах.
- Источник света один, читаемый: голая лампочка на проводе, абажур, окно. Вокруг лампы мягкое гало.
- Три световых режима: (а) тёплый жёлто-зелёный «быт», (б) холодный синий ночной, (в) **красный «ад»**: весь кадр тонируется красным, герои становятся красно-коричневыми, фон темнеет.
- Монстр — чёрный силуэт, видны только глаза, иногда зубы/рот светлой щелью.

### 1.3 Композиция
- Крупная плоская сцена, камера статична, как в театре: **горизонтальный «пол»** в нижней трети, герой стоит ногами на нём.
- Герой маленький относительно монстра (масштабный контраст 1:2–1:3); монстр часто **вылезает за край кадра** (рука, голова обрезаны).
- Симметрия и «рамки» из предметов на стене (ковёр, часы, календарь, дверь) задают тип помещения без текста.
- Слева-справа: двое в профиль/анфас друг напротив друга, диалог.
- Надпись как элемент мира (кровавая надпись на стене) — крупно, на весь кадр, с потёками. У нас: делаем в Remotion кодом, не нейросетью.

### 1.4 Форма героев
- Простые плоские фигуры, толстый ровный контур **не нужен** (контур тонкий тёмный/отсутствует), без градиентов, 2–3 тона на материал.
- Реалистичные пропорции, но упрощённые: небольшая голова, вытянутые вертикальные позы, опущенные руки. Лицо — точки-глаза, брови, линия рта. Эмоция читается бровями и ртом, а не «большими глазами».
- Бытовая уставшая «обычность» героя: майка, домашние штаны.
- Монстры: высокие (до потолка), тонкие длинные конечности, пустое тело, горящие глаза.

### 1.5 Субтитры
- Один блок из 1–2 строк, **по центру, в нижней трети** (на листе ~у ног героя), без плашки.
- Белый текст, лёгкая тёмная обводка/тень, гротеск (жирность Regular–SemiBold), небольшой размер (~3% высоты кадра). Ключевая реплика может быть **жирнее**.
- Целая фраза (до 6–8 слов), а не по 2–3 слова. Без подсветки текущего слова.

### 1.6 Ритм монтажа
- Короткие статичные планы 2–5 с, склейки по смене реплики; диалог строится на «пинг-понге» план героя / план монстра.
- Эскалация: бытовой спокойный кадр → тьма и силуэт → **красный** в пике → резкий возврат к быту и бытовая шутка-удар в конце (анти-климакс).
- Движение скупое: микроколебание, медленный наезд, вылезающая рука; резкие акценты только на ударах.

## 2. Правила кадра 1080×1920

Зоны (по высоте, сверху вниз):
- 0–6% (0–115 px): технический запас, ничего важного.
- 6–60% (115–1150): **сцена/действие**; глаза и лица героев на уровне 28–48% (540–920 px).
- 60–76% (1150–1460): пол, ноги, предметы переднего плана; можно перекрывать затемнением.
- **76–90% (1460–1730): зона субтитров** (центр y≈1600), ширина текста ≤ 900 px (боковые поля 90 px). Здесь нет ничего светлого и важного; под текст кладём градиент затемнения снизу 0→55%.
- 90–100% (1730–1920): запас под интерфейс платформы (кнопки, подпись).
- Правые 120 px на высоте 1000–1700 — не ставить важное (иконки Shorts/Reels).

Правила:
1. Один фон-слой шире кадра: генерируем **1620×1920 (1,5× по ширине)** или 2160×2560, чтобы работали панорама и параллакс без «краёв».
2. Герой в кадре: рост 650–900 px (full body) или по пояс (лицо ~420 px) в крупном плане; ноги не ниже y=1400.
3. Монстр может занимать весь кадр и выходить за границы; у монстра всегда видны глаза в зоне 20–45%.
4. Одно «главное» действие на кадр, один акцентный цвет.
5. Параллакс: 3 слоя (дальний фон 0.3×, средний 0.6×, герой/передний 1.0×); сдвиг ≤ 40 px, наезд камеры ≤ 12% за план; тряска амплитуда 6–20 px на 3–8 кадров.
6. Свет и виньетка делаются **в Remotion** (оверлей), а не запекаются в картинку: фоны генерируем «нейтрально освещёнными», тон меняем оверлеем (multiply/overlay) и цветокоррекцией.
7. Текст в кадре (надписи, вывески, часы) — только кодом.
8. Субтитры: шрифт Montserrat (SIL OFL, у нас уже в проекте), 46–52 px, вес 600, белый `#FFFFFF`, обводка `#000` 6 px + тень; акцентное слово `#FFE04A`; не больше 2 строк по ≤ 28 символов. Выше этой серии в `script.json` режим «мелкие субтитры по фразам».

## 3. Слои для одной серии (список генерации)

Общее: PNG, **прозрачный фон** для всех персонажей/реквизита (генерировать на однотонном `#00FF00`/серый фон и вырезать; см. риски), персонаж-спрайты одного размера холста 1024×1536 с общей точкой «ног» (нижний центр) и неподвижной головой/телом между сменами рта.

### 3.1 Фоны (6–7 штук на серию, без персонажей, нейтральный свет)
1. **BG-01 Квартира/укрытие, день, тёплый** — основная комната, пол в нижней трети, окно слева, стол, ящики. (Универсальная «база».)
2. **BG-02 То же помещение, ночь, холодный** — другой свет, горит лишь лампа/свеча (можно получить оверлеем, но один кадр генерим отдельно для честного света).
3. **BG-03 Тёмный коридор/подъезд**, одна лампочка сверху, дверь в конце.
4. **BG-04 Улица/двор апокалипсиса, сумерки**, брошенные машины, силуэты домов (широкий, под панораму).
5. **BG-05 Магазин/склад/АЗС изнутри**, жёлто-зелёный люминесцентный свет, стеллажи.
6. **BG-06 Крыша/выход на небо**, закат, дым вдали (для финала-шутки).
7. **BG-07 Крупный план детали** (дверь с замком/окно с заколоченными досками), для вставок.
Каждый фон — 2 слоя: **дальний** (стена/небо) и **передний** (мебель/пол, стойки двери, рамка окна) для параллакса; для 1–2 фонов ещё слой «свет из окна» (световое пятно, screen).

### 3.2 Герой (один основной + один второстепенный) — набор спрайтов
Базовое тело (без рта и бровей, чтобы их менять отдельно):
- Позы (full body, 4 ракурса: анфас, ¾ влево, ¾ вправо, спина): **стоит расслабленно, стоит напряжённо, сидит за столом (по пояс), идёт/крадётся, бежит (2 кадра), присел/прячется, поднял руки, держит биту/кастрюлю/банку (реквизит приклеен к руке отдельным слоем)**, лежит/упал.
- Руки: отдельные слои «рука опущена», «рука в кармане», «указывает», «закрывает рот» — для нейросети безопаснее рисовать руку отдельно по запросу «hand in simple mitten shape».
- Голова крупно (портрет 1024×1024) отдельно для крупных планов.

Выражения (слой «брови+глаза», 8 штук): нейтральное, усталое-безразличное, удивление, испуг, злость, ехидная ухмылка (глаза), закрыты (моргание), «пустой взгляд». Блинк — отдельный кадр «глаза закрыты».

**Viseme-набор рта (8 спрайтов, 200×140, поверх головы по якорю):**
| # | Рта | Звуки (рус.) |
|---|---|---|
| 0 | закрыт, линия | пауза, М Б П |
| 1 | чуть приоткрыт | Т Д Н Л, СЧ |
| 2 | широкая «улыбка» узкая щель | И Е Э |
| 3 | круглое «О» среднее | О Ё |
| 4 | маленькое «У» вытянутое | У Ю В Ф |
| 5 | широко открыт | А Я |
| 6 | зубы на нижней губе | В Ф |
| 7 | кричит (очень широкий) | для крика/эмоции |
Плюс эмоциональные варианты закрытого рта: ухмылка, гримаса, дрожь (3 шт.).
Anim: `phoneme → viseme` по таймингам слов из `tts.py`, смена не чаще 1 раза на 2–3 кадра, моргание каждые 2–4 с.

Второстепенный/напарник: тот же состав, но урезанный (5 поз, 4 выражения, те же 8 висем).

### 3.3 Зомби (4 типа, чёрные/тёмные силуэты с акцентом)
1. **«Бытовой» ходок** — обычная одежда (рабочий/офис), серая кожа, пустые глаза; 3 позы: стоит, шаркает (2 кадра), тянется. Жёлтое/белое свечение глаз. Комичен.
2. **«Длинный» (силуэт-монстр)** — аналог референса по приёму: до потолка, тонкие конечности; чёрная заливка, светящиеся глаза и щель рта. Руки отдельными слоями (вытянуть из-за края кадра). Для «ужас-момент».
3. **«Бегун»** — худой, согнутый, бежит; 2 кадра бега + прыжок; красные глаза.
4. **«Толстяк/Танк»** — большой, в рваной форме (повар/охранник), с цепью или дверью в руке; медленный, шумный. Для гэга и преграды.
Каждому: тело, отдельно голова (поворот), отдельно челюсть (открыть/закрыть), слой «глаза-свечение» (для пульсации в Remotion), мини-версия «толпа вдали» (силуэты 1 цвет).

### 3.4 Реквизит (отдельные PNG, прозрачный фон, ~512 px)
Бита, кастрюля-щит, консервная банка, банка тушёнки, рация, фонарик (+слой луча), нож/кухонный, бутылка воды, мешок крупы, топор, рюкзак, дверной замок/засов, заколоченные доски (набор 3), баррикада из мебели, часы (без цифр, стрелки кодом), календарь (пустой, цифры кодом), лампа-абажур, лампочка, телефон (экран пустой, контент кодом), еда (хлеб, пачка лапши), чемодан, аптечка (без надписей), след/пятна/брызги (набор 6), трещины/дыра в стене, дым/туман (полупрозрачный).

### 3.5 Служебное (кодом, не нейросетью)
Виньетка, зерно, красный оверлей, световые пятна, пыль в луче, титры/надписи/«кровавая» надпись, часы-стрелки, цифры календаря, вспышка-удар, затемнение, ч/б «удар».

## 5. Монтажная схема серии 75 с (черновик, 14 сцен)

Всего 14 планов, ср. 5,3 с; диалоги сменой плана, не плавно. Тип: `S` статика+микродвижение, `Z` наезд, `P` панорама/параллакс, `X` удар.

| # | Время | Длит. | Сцена / слой | Камера | Свет/звук |
|---|---|---|---|---|---|
| 1 | 0–4 | 4 | **Хук**: герой в BG-01 обыденно (быт) + провокационная реплика | S, лёгкий дрейф 1% | тёплый свет, голос сразу, на 0,5 с без паузы |
| 2 | 4–9 | 5 | Правило выживания №N (герой объясняет, жест рукой) | Z +6% | тёплый |
| 3 | 9–14 | 5 | Что-то снаружи: окно/дверь, тень зомби-ходока | P параллакс 30 px | холодный, глухой стук |
| 4 | 14–19 | 5 | Крупный герой, реакция (раздражение, не страх) | S | тёплый, юмор |
| 5 | 19–24 | 5 | Зомби в проёме (силуэт глаза), герой по-прежнему «бытово» | Z +8% | свет мигает, **удар-звук** тихий |
| 6 | 24–30 | 6 | Эскалация: он делает нелепое действие (пример-урок) | P | тёплый |
| 7 | 30–35 | 5 | Ошибка героя → зомби сильнее (Длинный выходит из тьмы) | Z +10% | сине-чёрный, музыка вниз |
| 8 | 35–40 | 5 | **Тишина (1,2 с без музыки и голоса)**, только глаза во тьме | S, застыла | почти чёрный кадр, глаза-свечение пульсируют |
| 9 | 40–45 | 5 | **Красный свет №1**: монстр нависает, герой маленький | Z +12% + тряска 14 px | красный оверлей 0→80% за 8 кадров, **удар** |

| 14 | 70–75 | 5 | **Анти-клаймакс-шутка** + хвост на следующую серию (зомби вежливо «просит добавки») | S → резкая склейка в чёрный | тёплый, 1 «пинг» звука |

Правила ритма:
- **Красный свет**: 2 раза (9 и 10–11), суммарно 12–15 с, не больше 20% ролика; вход быстрый (6–8 кадров), выход — белая вспышка 3 кадра.
- **Тишина**: 1,2–1,5 с в 35–40 с, перед красным; ещё микро-тишина 0,7 с в 61 с.
- **Удары (X)**: 3 на серию (24 с слабый, 40 с главный, 55 с развязка). Каждый: тряска 6–20 px, 3–8 кадров, + hit-sfx + короткая задержка звука фона.
- Камера: наезд только по выбору, максимум 12% за план; в юморных сценах камера статична; панорама — при выходе в новое место.
- Первые 3 с: герой уже говорит, титры идут с первого слова (удержание).
- Музыка: тихая петля-ambient, коммерческая лицензия записывается в `sources.md`; под красный — низкий дрон.

## 6. Риски нейросетевой генерации и обход

| Риск | Проявление | Как обходим |
|---|---|---|
| **Консистентность героя** | лицо/одежда «плывут» между кадрами | одна «базовая» картинка-референс (character sheet), всегда подаём как reference/IP-adapter/LoRA (если есть); фиксируем seed и палитру; **одну позу делаем один раз**, все вариации — слоями (поза тела + лицо отдельно, мимика — Remotion), а не новыми генерациями; в промпте повторяем 6 констант: «dark messy hair, stubble, white sleeveless undershirt, dark blue sweatpants, tan skin, tired eyes». |
| **Руки/пальцы** | лишние пальцы, слипшиеся | варежко-подобные упрощённые руки в стиле («simple mitten hands»); руки по возможности в карманах/за спиной/на реквизите; крупные планы рук не делаем; плохие руки **подменяем** набором из 4–5 заранее выбранных/нарисованных кодом рук (SVG), приклеиваем слоем; запасные кадры «рука за кадром». |
| **Текст в кадре** | кракозябры на вывесках/часах | в негативе `text, letters, numbers`; все надписи, цифры часов/календаря, вывески и титры **накладываются кодом**; если на фоне вывеска нужна — оставляем пустую плашку; в QA выбраковка по тексту. |
| **Вырезка фона** | кайма, потерянные тонкие части | генерим на однотонном `#00FF00` фоне (без теней), вырезка chroma-key + `rembg`/маска вручную, обрезка 1–2 px; тонкие руки монстров рисуем отдельным слоем. |
| **Разный масштаб/якорь** | прыгает при смене позы | единый холст 1024×1536 и точка «ног»; после генерации скрипт нормализации (bbox → baseline y=1480); головы — по якорю «шея». |
| **Освещение «поехало»** | фоны в разном стиле | в ТЗ каждого фона один световой режим; дальнейшее освещение — оверлеем Remotion; в серию кладём 1 «ключевой» фон и берём остальные в том же промпте с `same room, different angle`. |
| **Стиль «поплыл» к 3D/аниме** | глянец, большие глаза | негатив из 4.2; при первом батче выбираем 3 лучших и зашиваем в reference; регулярно сравнивать на общем листе. |
| **Viseme/рты не совпадают** | разные размеры, соседние лицо | рты рисуем один раз **кодом (SVG)** или вырезаем из одной сетки; якорь по носу; запасной режим «открыт/закрыт» 2 спрайта. |
| **Гор и безопасность платформ** | демонетизация | кровь только намёком (потёки, тёмное), без расчленёнки; зомби — комичные; в промптах `comic not gory`. |
| **Авторство/лицензия** | чужой стиль | не просить «в стиле <имя студии/ролика>»; описываем словами (как в 4.1); проверить условия коммерческого использования у генератора и записать в `sources.md` (модель, дата, версия). |
| **Затраты на повторы** | много промптов | генерируем пакетами по 4, выбираем 1, ведём `assets/prompts.md` с seed и ссылками. |
