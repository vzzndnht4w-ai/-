# video-factory — вертикальные ролики (1080×1920, 30 fps) кодом на Remotion

Формат: объясняющие шорты на русском. Тёмный фон с неоновыми плашками-инфографикой + мультяшные сцены,
озвучка TTS, субтитры по 2–3 слова (текущее слово на жёлтой плашке). Образец стиля — ролик, который показал владелец (про контракт оператора БПЛА).

## Как делаем видео
Команда `/make-video <тема>` (скилл `.claude/skills/make-video`) ведёт по этапам и использует агентов из `.claude/agents/`:
исследователь → сценарист → режиссёр → (TTS) → моушн-дизайнер → контролёр.

Файлы одного видео: `videos/<slug>/{sources.md, script.json, timeline.json}`; озвучка → `public/audio/<slug>.mp3`.

Команды:
- `python3 scripts/tts.py <slug>` — озвучка и тайминги слов (edge-tts, `ru-RU-DmitryNeural`); `--fake` — без сети и звука, только для проверки вёрстки
- `node scripts/render.mjs <slug>` — `out/<slug>.mp4`; `--still=<сек>` — кадр `out/<slug>.png`
- `npm run studio` — предпросмотр; `npm run typecheck`

## Правила
1. **Каждая цифра на экране и в озвучке — с источником** в `videos/<slug>/sources.md` (URL + дата). Нет источника — не говорим. Темы про законы, выплаты и т. п. меняются: пишем дату актуальности и зовём поправить в комментариях.
2. **Всё оригинальное.** Графика рисуется кодом. Чужие кадры, музыка и шрифты без лицензии не используются. Проект монетизируется, поэтому **код из репозиториев с лицензией PolyForm Noncommercial (anything2explainer, video-talkcraft) не копируем**; идеи — можно, текст и код — нет. Шрифт Montserrat — SIL OFL (можно). Музыку берём только с лицензией, допускающей коммерцию, и записываем в `sources.md`.
3. **Цветовой код:** жёлтый — нейтральная информация, зелёный — плюсы, красный — риски/минусы; красноватый фон (`mood: "danger"`) — блок рисков.
4. Субтитры: ≤3 слова на блок. Верх кадра (до ~42% высоты) — инфографика, низ — субтитры; их не перекрывать.
5. Триггер появления плашки — слово из озвучки (`cue`), а не номер кадра: правка текста не ломает тайминги.
6. Перед сдачей: `typecheck`, рендер контрольных кадров по каждой сцене и просмотр глазами.
7. Окружение: исходящий доступ ограничен. Для настоящей озвучки нужен хост `speech.platform.bing.com`; без него — `--fake` или запуск `tts.py` на своей машине.
